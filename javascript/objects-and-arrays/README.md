# Objects and Arrays

## Progressive object API sequence
Object.keys(), Object.values(), Object.entries(), Object.fromEntries(), Object.hasOwn(), Object.assign(), Object.freeze(), Object.seal(), Object.create(), Object.defineProperty(), property descriptors, getters/setters, and prototypes.

## Progressive array API sequence
map(), filter(), reduce(), find(), findIndex(), some(), every(), flat(), flatMap(), sort(), toSorted(), splice(), slice(), Array.from(), and Array.of().

For every API, cover:
1. What it does and what it returns
2. Whether it mutates the original
3. Behavior with missing, inherited, or unusual values
4. A practical use case
5. Output prediction and debugging exercises

Do not teach the entire list in one session; introduce methods in dependency-aware groups.
